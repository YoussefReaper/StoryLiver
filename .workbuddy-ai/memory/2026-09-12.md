## THE BUG THAT BLOCKED THE USER'S OWN PREMISE (real, mode-independent)
Premise: `I and my girlfriend charlie (from hazbin hotel) in Demon Slayer verse`.
The build produced a faithful Demon Slayer world with **no Charlie in it** — the
exact failure the handoff thought it had fixed. `_seat_imports` can only seat
somebody the PARSER found, and the parser found nobody:
- `_IMPORT_PATTERN` knows one shape, `Character from Source`. The player wrote
  `charlie (from hazbin hotel)` — a parenthesis, lowercase. `imports` came back
  empty, so no seat, no persona, no friction.
- `looks_like_premise` did not treat a parenthetical as a crossover signal, so a
  ≤6-word crossover was taken as a bare title and `parse_premise` returned early.
- `Charlie from Hazbin Hotel in Demon Slayer` recorded the source as
  `"Hazbin Hotel in Demon Slayer"` — `in` is a connective inside a title
  ("Made in Abyss"), so the pattern ran through the word introducing the host.

Fixes (all in `backend/research.py`, + `canon_seed.known()`):
- `_PAREN_SOURCE` + `_name_before()` (the token touching the bracket, extended
  left only over capitalised words — so "my girlfriend charlie" is charlie and
  "Charlie Morningstar" is one person) + `_titleish()` (gives a typed-lowercase
  name its capitals back, idempotent, small words stay small).
- `looks_like_premise` treats a parenthesised source as a premise only beside a
  `from` or a host phrase, so `Kimetsu no Yaiba (manga)` and `Made in Abyss` are
  still titles.
- Source-swallows-host trimmed back, but only when the leftover half is an exact
  `canon_seed` alias — otherwise "Made in Abyss" would become "Made".

## New infrastructure
- `tools/probe_setting.py` — dump what the builder makes of a premise offline.
- `tools/play.py` — drives the REAL `engine.take_turn` over a session; writes a
  transcript, every prompt to `prompts/`, and `spool/misses.json`.
- `backend/llm.py` spool mode (`STORYLIVER_LLM_MODE=spool`): completions come
  from `spool/responses.json` keyed by a hash of the prompt, so a playthrough
  can be played and replayed with **no key and no spend**. On a miss it records
  the request and uses the offline stub so the run still completes → author in
  passes, converge. `STORYLIVER_SPOOL_STUB_ROLES` keeps npc/director on the free
  stub.
